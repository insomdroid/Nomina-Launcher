# Nomina

Nomina is a personal Android launcher project based on [ARK Launcher](https://github.com/jrs8205/ARK-launcher), with changes and additions made to suit my own needs.

This is an independently maintained personal project. It is not affiliated with or endorsed by the ARK Launcher authors.

## Build

APK builds are available from [GitHub Actions](https://github.com/insomdroid/Nomina-Launcher/actions).
