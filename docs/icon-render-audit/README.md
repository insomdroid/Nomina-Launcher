# Icon Render Audit

Upload screenshots of Nomina's current app icon rendering to this folder.

Suggested screenshots:

- `drawer-light.png` — App Drawer in light mode, showing several app icons.
- `drawer-dark.png` — App Drawer in dark mode.
- `zoom.png` — an icon that appears enlarged or fills its container.
- `solid-black.png` — an icon that becomes entirely black or a solid silhouette.
- `unchanged.png` — an icon that does not become monochrome.
- `other-icons.png` — any other examples that show inconsistent sizing, spacing, or rendering.

Please include the full App Drawer in at least one screenshot so the icon size and spacing can be evaluated in context. Avoid cropping individual icons too tightly.

Screenshots only; do not include APKs or private information.
